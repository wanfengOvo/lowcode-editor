
# 使用 React 18 + TypeScript + Zustand 实现的低代码编辑器

## 🚀 实现功能

- **组件拖拽**：支持跨层级拖拽组件，灵活布局。
- **预览与编辑**：支持预览和编辑模式。
- **复制粘贴**：支持复制粘贴组件。
- **撤销/重做 & 时间轴**：支持撤销、重做操作，并可通过时间轴回溯任意编辑节点。
- **事件绑定**：支持组件内置事件绑定及自定义事件配置。
- **React 代码生成**：根据JSON配置生成 React 代码（功能持续完善中）。

---

## 🛠️ 安装依赖

```bash
npm install
```

## ▶️ 运行项目

```bash
npm run dev
```
